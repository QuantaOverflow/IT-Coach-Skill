# IT培训 Skill

> 培训班花 2 万教的那套东西，我全开源了。

这是一套给 **低学历 / 转行 / gap / 培训班出身** 求职者用的 Claude Code Skill。

不讲正确的废话。只给能用的话术、能绕的策略、能过的面试。

---

## 它能帮你做什么

### `/it-diagnose` — 背景诊断，告诉你能不能转、学什么方向

> "我 32 岁大专，做了 8 年销售，想学 Java，有没有机会？"

**不会跟你说"努力就有希望"。** 会告诉你：Java 的门对你已经关了，真正能走通的方向只有这两条，分别要多久、起薪多少、风险在哪。

---

### `/it-resume` — 简历包装，培训班项目也能写得有说服力

> "我培训班做的谷粒商城项目，简历怎么写不被 HR 秒识别？"

**不会告诉你"诚实展示自己"。** 会直接给你改写后的项目描述，哪些话术是禁区，哪些是行业惯例，一档一档说清楚。

---

### `/it-interview` — 面试话术，包括被问"你是培训班出来的吧"怎么接

> "面试官说他这个月已经面了 5 个一模一样架构的项目，让我交个底。"

**不会教你否认。** 会告诉你什么时候否认、什么时候承认+重构叙事，以及被追问项目规模、团队协作、上线情况时各自怎么答。

---

### `/it-apply` — 投递策略，哪些公司是雷、哪些是真机会

> "投了几十份没有回音，是简历问题还是投错地方了？"

告诉你培训班简历的黑名单公司（B 轮-C 轮互联网产品公司，直接拉黑）、真正容忍度高的企业类型、Boss 直聘几点发消息回复率最高，以及没有内推人脉时怎么找。

---

### `/it-negotiate` — 薪资谈判，弱背景也能不被随便压价

> "HR 说这是他们能给的最高了，我要不要接？"

给你判断依据：大公司说最高通常是真的，小公司说最高通常是试探。怎么分辨、怎么用"有其他面试在推进"制造压力，以及被压价后转而谈什么条件。

---

### `/it-router` — 不知道用哪个？从这里开始

模糊问题自动分流，帮你判断现在处于求职的哪个阶段、该用哪个工具。

## 安装

```bash
claude plugin install github:QuantaOverflow/IT-Coach-Skill/plugins/it-training
```

安装后直接在 Claude Code 里调用：

```
/it-router 我想转行 IT，32 岁，大专，做了 8 年销售
/it-diagnose 我该学 Java 还是测试？
/it-resume 帮我看看这份简历
/it-interview 面试官问我空窗期怎么解释
/it-negotiate 公司给了 10k，我要怎么谈
```

---

## 为什么这套东西有用

2026 年的 IT 初级岗位比 2023 年少了 35%，但培训机构还在按 2020 年的话术招生。

这套 skill 的底层逻辑来自对 **培训机构就业辅导 SOP、HR 筛选机制、背调风险边界** 的系统性研究。不是鸡汤，不是方法论，是一套在信息不对称的招聘市场里能用的策略。

所有薪资数据和市场判断基于 2026 年春招数据，每季度建议核对一次。
