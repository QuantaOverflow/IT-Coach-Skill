# 诊断案例库

## 案例A：大龄低学历断粮危机者

**背景**：男，31岁，非统招大专，线下门店销售，空窗8个月，逻辑弱，3个月内必须就业

**机构常见错误推荐**：忽悠贷款学Java，承诺包装成5年老手月薪15k

**正确诊断**：
- 触发硬性排除：非统招大专 → 排除Java/AI/数据分析
- 触发硬性排除：3个月急需就业 → 排除所有长周期方向
- 触发硬性排除：31岁+逻辑弱 → 传统代码岗完全关闭

**推荐方向**：AIGC内容创作（电商营销方向）

**执行策略**：
- 1-2个月学AIGC工具（AI电商图生成、爆款短视频脚本批量生产）
- 定位为"具备AI提效能力的电商运营/营销专员"，不是IT技术岗
- 目标：传统商贸企业，起薪7k-8k，立即止血

## 案例B：名校非科班跨界潜力股

**背景**：女，26岁，统招985本科（土木工程），刚辞职无空窗，高数优秀，逻辑强，存款充裕可等半年

**机构常见错误推荐**：认为女生适合"轻松安稳"的软件测试

**正确诊断**：
- 通过所有AI应用开发的条件
- 名校本科+强逻辑+有时间=最优AI转行人选
- 推荐测试是对其资产的严重贱卖

**推荐方向**：AI应用开发（Agent/RAG方向）

**执行策略**：
- 6个月扎实学Python + LangChain + 国产大模型接入
- 结合土木专业做差异化项目：建筑工程规范自动合规审查Agent
- 通过脉脉联系相关业务线Leader内推
- 预期起薪：15k+

## 案例C：应届二本迷茫白纸

**背景**：男，22岁，统招普通二本（行政管理），应届无经验，数学差但逻辑尚可，家人支持可等半年

**机构常见错误推荐**：全栈开发或前端（宣称年轻就是本钱）

**正确诊断**：
- 数学差 → 排除数据分析
- 无行业背景 → 不适合AI应用开发
- 前端2026年正遭AI替代 → 不推荐
- 二本学历+22岁+逻辑中等 → 最适合自动化测试

**推荐方向**：Python自动化测试

**执行策略**：
- 4个月学接口测试框架 + CI/CD
- 起薪7k+，22岁有10年职业安全期
- 后续引入AI自动测试用例生成工具，向测试开发方向演进
