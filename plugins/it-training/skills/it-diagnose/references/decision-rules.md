# 诊断决策规则

## 五个输入变量

收集学员信息时，必须确认这5项：

1. **学历**：初中/高中/大专（统招or非统招）/本科（统招or非统招）/研究生
2. **年龄**：具体年龄
3. **原职业背景**：无业/学生、服务业、销售/市场、行政文职、非IT理工科、其他IT相关
4. **空窗期**：无/6个月内/6-12个月/1年以上
5. **经济压力**：急需就业（3个月内）/可等待6个月/不急（1年内）

数学逻辑基础可从原职业/专业推断，不需要单独问。

---

## 硬性排除规则（先过这关）

以下组合直接排除对应方向，无论其他条件多好：

| 背景组合 | 排除方向 | 原因 |
|---|---|---|
| 高中/非统招大专 + 任何年龄 | Java、AI应用开发、数据分析 | ATS机器过滤，简历进废件箱，没有面试机会 |
| 32岁以上 + 无IT经验 | Java、前端、AI应用开发 | 企业不要大龄初级代码工人，面试通过率趋近于零 |
| 纯文科/行政后勤 + 数学弱 | 数据分析、AI应用开发 | 学习阶段会在算法部分彻底崩溃 |
| 急需就业（3个月内） | Java、前端、AI应用开发、数据分析 | 这些方向学习周期5-8个月，3个月速成=面试必死 |

## 最优人群映射（排除后的正向匹配）

| 推荐方向 | 最优背景组合 | 核心逻辑 |
|---|---|---|
| AI应用开发 | 统招本科（理工）+ 22-26岁 + 强逻辑 + 英语可 + 可等半年 | 风口+理工底子+年轻，最佳组合 |
| 数据分析 | 统招本科及以上 + 28-32岁 + 原销售/市场/供应链 + 中强数理 | 业务经验是真正的竞争壁垒 |
| 软件测试 | 统招大专/普通二本 + 24-28岁 + 行政文职/非理工 + 经济压力中等 | 门槛匹配，快速就业 |
| AIGC内容创作 | 任何学历 + 30岁以上 + 有审美/营销/设计背景 | 年龄反而是优势，行业经验直接变现 |

## Tiebreaker：多方向同时适合时的裁决

当候选人满足多个方向的基础要求时，追加三个问题：

**Q1：风险偏好**
- 厌恶风险，要确定性 → 软件测试
- 想自由职业/接单 → AIGC内容创作
- 有技术野心，想走管理/产品 → 前端（作为跳板）

**Q2：社交驱动力**
- 排斥在脉脉/GitHub包装自己 → 排除AI应用开发（该方向75%靠内推/猎头）
- 愿意主动社交求职 → AI应用开发或数据分析

**Q3：原行业是否有深度**
- 有5年以上某行业沉淀 → 数据分析（行业经验是核心壁垒）
- 无行业背景 → 按年龄和学历匹配
